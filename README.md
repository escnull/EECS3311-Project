# AI Investigation Game (EECS 3311 Course Project)

An AI-powered open-world detective game. Each investigation is generated by an LLM from a
structured case template (murder or theft), and you play it by exploring locations, searching
objects, questioning suspects and typing free-form actions that an AI agent turns into game commands.
A deterministic game system validates every action, so the AI can never break the rules or the case.

Both a **GUI** (Swing) and a **CLI** are included. They call the same `GameController`.

## Prerequisites

- Java **17 or newer** (`java -version`)
- Optional: Maven 3.8+ (only needed to run the unit tests or build a jar)
- An LLM API key. The default is Anthropic Claude (`claude-haiku-4-5`, a cheap model).
  Any OpenAI-compatible API also works, including free ones (Groq, Google Gemini) or a local Ollama model.

The application has **no runtime dependencies**, so it builds with only a JDK.

## 1. Configure your API key (local only)

```bash
cp .env.example .env        # Windows: copy .env.example .env
```

Open `.env` and replace `YOUR_LOCAL_API_KEY_HERE` with your key. `.env` is listed in `.gitignore`
and must never be committed. Environment variables named `LLM_*` override the file.

| Setting | Meaning |
|---|---|
| `LLM_PROVIDER` | `anthropic` (default), `openai` (any OpenAI-compatible endpoint) or `offline` |
| `LLM_API_KEY` | Your key |
| `LLM_MODEL` | e.g. `claude-haiku-4-5`, `llama-3.3-70b-versatile`, `gemini-2.0-flash` |
| `LLM_BASE_URL` | Required for `openai` (see examples in `.env.example`) |

## 2. Run

Without Maven:

```bash
./run.sh            # GUI
./run.sh --cli      # CLI
```
On Windows use `run.bat` / `run.bat --cli`.

With Maven:

```bash
mvn package
java -jar target/ai-investigation-game.jar          # GUI
java -jar target/ai-investigation-game.jar --cli    # CLI
```

`--offline` runs without any LLM, using a rule-based stand-in (`OfflineLLMClient`) and two
built-in sample cases. It exists for testing and for running without network access; the real
game experience (generated cases, dialogue, narration, lead suggestions) needs an LLM.

## 3. Run the tests

```bash
mvn test
```

The tests cover command validation, state transitions, save/load (including corrupted files),
memory retrieval, the agent's validation of LLM output, and the Claude client against a local fake server.
They do not need an API key.

## Example CLI session

```
create Sam Perceptive,Charismatic
new murder 1920s English country house
look
search desk
ask edmund where were you last night?
go to the kitchen and search the drawer      <- free text, planned by the AI agent
suggest                                      <- agent proposes leads from your evidence
objectives
history glove
save
accuse clara
```

Type `help` in the CLI for every command. Anything that is not a command is sent to the AI agent.

## GUI overview

- **Investigator** panel: name, attributes, reputation.
- **Map**: click a location to move (locked ones explain what you need).
- **Search here**: one button per searchable object at your location.
- **Conversation**: type any action for the agent, or pick a person and ask a question.
- **Tabs**: Case File, Leads (Suggest Connections / Confirm / Dismiss), Objectives, History (filterable), Accuse.
- **Game menu**: New Investigator, New Investigation, Save, Save As, Load, Abandon Case.
- Status bar: game state, location, turn and LLM token usage.

## Project structure

```

  Main.java                 entry point (--cli, --offline)
  controller/               GameController (Command invoker, used by GUI and CLI)
  agent/                    AgentController, MemoryManager, PromptBuilder, FactChecker
  agent/strategy/           AgentStrategy, TruthfulStrategy, EvasiveStrategy (Strategy)
  casegen/                  CaseCreator, MurderCaseCreator, TheftCaseCreator (Factory Method), CaseValidator
  command/                  GameCommand, MoveCommand, SearchCommand, QuestionNpcCommand, AccuseCommand (Command)
  state/                    GameState, NoCaseState, InvestigatingState, SolvedState (State)
  observer/                 GameObserver (Observer)
  model/                    Game, Case, Investigator, NPC, Evidence, Location, Lead, Objective, GameEvent
  llm/                      LLMClient, AIClient (Claude), OpenAICompatibleClient, OfflineLLMClient
  ui/                       GameGUI, GameCLI, EventFormatter
  util/Json.java            small JSON reader/writer
src/test/java/investigation/ unit tests
```

## Security

- Real keys live only in `.env` (git-ignored). `.env.example` contains placeholders.
- Keys are never logged, printed, saved in save files, or sent anywhere except the configured LLM endpoint.
- If a key is ever pushed by mistake, revoke it immediately and remove it from the repository history.
